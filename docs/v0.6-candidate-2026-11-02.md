## Not complete

The headless run does not verify Korean glyph rendering, visual layout,
controller/key labels, menus, Set Builder, quest/gameplay coverage or save/load.
It also cannot establish the semantic correctness of every recovered translation.
The tool marks `translationReviewComplete=false` and `gameVerified=false`.
The candidates were used only in a detached test copy and are not published as
a compatible v0.6 release. The supported v0.5 baseline and watcher state remain
unchanged. Continue with the quarantined/new-context strings before packaging.
